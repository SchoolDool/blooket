How can we help?

How do I create my first set?

Go to Create, pick a set title, add questions, and publish when ready.

Can I import Quizlet sets?

Yes. Use the import option in Create, then review and save.

How do I host a live game?

Select a set and choose Host. Share the game code with players.

What game modes work best for review?

Gold Quest and Battle Royale are great for fast-paced class review sessions.

How do I reset my password?

Use the Forgot Password link on sign-in and follow the email steps.

Where can I manage subscription settings?

Open Account Settings and navigate to the Billing section.

How can I keep students engaged?

Rotate game modes, enable team play, and keep sessions short and frequent.

Can I assign homework challenges?

Yes. Choose Assign Homework and set a due date for asynchronous play.
